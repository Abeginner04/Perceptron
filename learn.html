📖 What is a Perceptron?

The Perceptron is a type of artificial neuron and one of the simplest models of neural networks. It was introduced by Frank Rosenblatt in 1958 and is primarily used for binary classification tasks.

🧠 Types of Perceptrons

🔹 Single-Layer Perceptron

Used for linearly separable problems.

  • Only one layer (input → output)
  • Uses a step function for activation
  • Can implement logic gates like AND, OR, NAND

🔸 Multi-Layer Perceptron (MLP)

Capable of learning complex non-linear functions.

  • Has input, hidden, and output layers
  • Uses non-linear activations (ReLU, Sigmoid, Tanh)
  • Trained using backpropagation

⚙️ How Does a Perceptron Work?

A perceptron takes multiple inputs, multiplies them by weights, adds a bias, and applies an activation function to produce an output:

Output: y = f(W·X + b)
Where:
  W = weight vector
  X = input vector
  b = bias
  f = activation function (e.g., step function)

🧪 Perceptron Learning Steps

  1. Initialize weights and bias
  2. Take an input vector and compute output
  3. Compare output with actual label
  4. Update weights if there's an error
  5. Repeat for all training samples

📘 Perceptron Learning Rule

The weights are updated using the following rule:

w_new = w_old + η (y - ŷ) x
Where:
  η = learning rate
  y = actual output
  ŷ = predicted output
  x = input vector
