🧠 Perceptron Algorithm in Python

📌 What is a Perceptron?

The perceptron is a type of artificial neuron that forms the foundation of neural networks. It’s used for binary classification tasks (e.g., YES or NO, SPAM or NOT SPAM).

🛠️ Perceptron Architecture

  • Inputs (x): Feature vector
  • Weights (w): Determines importance of each input
  • Bias (b): Shifts the decision boundary
  • Activation Function: Typically a step function
  • Output: Binary (0 or 1)

💻 Python Implementation

Below is a simple implementation of a perceptron to learn the AND logic gate.

# Perceptron for AND Gate
import numpy as np

# Step activation function
def step_function(x):
    return 1 if x >= 0 else 0

# Perceptron class
class Perceptron:
    def __init__(self, learning_rate=0.1, epochs=10):
        self.lr = learning_rate
        self.epochs = epochs
        self.weights = None
        self.bias = None

    def train(self, X, y):
        n_samples, n_features = X.shape
        self.weights = np.zeros(n_features)
        self.bias = 0

        for _ in range(self.epochs):
            for idx, x_i in enumerate(X):
                linear_output = np.dot(x_i, self.weights) + self.bias
                y_pred = step_function(linear_output)

                # Update rule
                update = self.lr * (y[idx] - y_pred)
                self.weights += update * x_i
                self.bias += update

    def predict(self, X):
        linear_output = np.dot(X, self.weights) + self.bias
        return [step_function(x) for x in linear_output]


# Input data for AND gate
X = np.array([[0, 0],
              [0, 1],
              [1, 0],
              [1, 1]])

# Expected output
y = np.array([0, 0, 0, 1])

# Create and train model
model = Perceptron()
model.train(X, y)

# Predict
predictions = model.predict(X)

print("Predictions:", predictions)

🔍 Output Explanation

If successful, the program will output:

Predictions: [0, 0, 0, 1]

This means the perceptron has learned the AND logic gate correctly!

⚠️ Limitations of Single-Layer Perceptron

  • Can only solve linearly separable problems
  • Cannot solve XOR problem
  • Struggles with complex datasets (e.g. image or speech recognition)

📈 What's Next?

To solve complex and non-linear problems:

  • Use Multi-Layer Perceptron (MLP)
  • Apply non-linear activation functions (ReLU, Sigmoid)
  • Train using Backpropagation + Gradient Descent
